# Al Aqsha Haji & Umrah

Landing page statis untuk informasi paket umroh Al Aqsha.

## Struktur proyek

- `index.html` — halaman web utama.
- `assets/` — aset aktif yang digunakan oleh website, termasuk gambar hero tawaf.
- `source-images/` — file gambar sumber/original sebagai arsip, termasuk logo lembaga.

## Menjalankan secara lokal

Jalankan perintah berikut dari folder proyek:

```powershell
python -m http.server 4173
```

Kemudian buka `http://localhost:4173` di browser.
